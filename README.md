# ai-markdown organization profile

This repository holds the public GitHub organization homepage.

- `profile/README.md`: organization homepage content.
- `assets/banner.svg`: editable, self-contained vector banner.

Keep package status aligned with the main repository and npm releases. Frameworks under development must not be described as released. Use absolute links in the profile because GitHub renders it on the organization overview.

Project documentation and contribution guidance live in [ai-markdown/ai-markdown](https://github.com/ai-markdown/ai-markdown).
